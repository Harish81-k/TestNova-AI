Slide 2: Project Overview

A comprehensive, AI-powered platform for education and technical evaluation

  • What is TestNova AI? TestNova AI is a robust, full-stack educational ecosystem designed to evaluate, train, and guide developers through multiple interactive paradigms. It seamlessly combines an AI-powered Chatbot, an integrated Live Coding Environment, structured Quizzes, comprehensive Assignments, and a highly gamified "Gaming Board" module into one unified platform.
  • Project Approach A team-developed MERN stack application applying advanced software architectures, including Role-Based Access Control (RBAC), generative AI API integration, real-time code execution, and complex React state management.
  • Target Experience Seamless navigation • Instant AI feedback • Interactive learning (Code, Quiz, Game) • Tiered premium access • Beautiful Glassmorphism aesthetics

Slide 3: Problem Statement & Objectives

Problem Statement Modern technical education is deeply fragmented. Students, developers, and recruiters typically have to use separate platforms for chatting with AI, solving coding challenges, taking quizzes, and testing logical reasoning. This fragmentation causes friction, and standard testing methods are often dry and anxiety-inducing. There is a strong need for a centralized, gamified, AI-integrated platform that combines learning, practice, and assessment under one cohesive, user-friendly system.

Objectives

  • Build a centralized, all-in-one educational platform spanning traditional and modern assessment methods.
  • Integrate Generative AI directly into the learning and assessment process.
  • Provide multiple evaluation methods: Live Coding Arenas, Quizzes, Assignments, and Logic Mini-games.
  • Implement a robust tiered subscription system (Free, Pro, Enterprise) with strict administrative oversight.
  • Deliver a visually stunning, responsive user interface that keeps users engaged.

Slide 4: Key Features (The 5 Pillars of TestNova AI)

Core functionality of the platform

  • 🤖 AI Chat Interface An integrated AI assistant capable of answering technical questions, explaining complex topics, and guiding users through personalized learning paths in real-time.
  • 💻 Interactive Coding Interface A built-in IDE environment (powered by Wandbox execution engines) allowing users to write, test, and execute code directly within the browser with real-time output.
  • 📝 Quizzes & Assignments Interfaces Structured testing environments allowing users to take timed multiple-choice quizzes and submit detailed technical assignments for comprehensive evaluation.
  • 🎮 Gamified Learning Board Pluggable, interactive mini-games spanning System Design, Cryptography, Memory, Code Debugging, and Logic Gates to gamify the testing process.
  • 🛡️ Role-Based Access & Admin Dashboards A robust tier system locking premium features behind Pro/Enterprise subscriptions, paired with a powerful control panel for admins to manage users, override plans, and ban malicious accounts.

Slide 6: Technology Stack

The modern stack powering our ecosystem

  • FRONTEND React.js (Vite), HTML5, Tailwind CSS3, JavaScript, Framer Motion
  • BACKEND Node.js, Express.js, RESTful APIs
  • DATABASE MongoDB (Atlas), Mongoose ODM

  • SECURITY bcrypt: Password Hashing & Secure Authentication JWT: Stateless Session Management

Slide 7: User Journey

End-to-end user flow across all features

Standard User Flow: Open TestNova AI ➔ Login / Register ➔ Select Subscription Plan ➔ Choose Path:

  1. Chat: Ask the AI for explanations or code reviews.
  2. Code: Open the Coding Interface to practice syntax.
  3. Assess: Take a timed Quiz or submit an Assignment.
  4. Play: Enter the Gaming Board to solve logic puzzles. ➔ View combined scores, history, and growth in the Profile Dashboard.

Admin Management Flow: View registered users ➔ Monitor platform usage ➔ Upgrade users to Pro/Enterprise ➔ Ban/Delete policy violators.
